# Processo Seletivo CodeX 2025.1 (Desafio 2)

[cite_start]Este projeto foi desenvolvido como parte da segunda etapa do processo seletivo da CodeX, empresa júnior de Sistemas e Computação da Universidade Federal de Campina Grande[cite: 3]. [cite_start]O objetivo era criar uma aplicação simples de autenticação para avaliar habilidades de trabalho em equipe, organização e conhecimentos básicos de desenvolvimento de software[cite: 8].

## Funcionalidades Implementadas

A aplicação cumpre todos os requisitos funcionais mínimos solicitados no desafio:

* [cite_start]**RF-01: Formulário de Login:** Uma tela inicial exibe um campo para que o usuário insira seu nome e um botão "Entrar"[cite: 40].
* [cite_start]**RF-02: Saudação com Nome:** Após o login, o usuário é redirecionado para uma tela de boas-vindas que exibe a mensagem "Bem vindo, <nome da pessoa>"[cite: 27, 40].
* [cite_start]**RF-03: Edição do Nome:** Na tela de saudação, um botão "Editar" permite que o usuário retorne à tela de login, com o campo de nome já preenchido, para alteração[cite: 28, 40].
* [cite_start]**RF-04: Logout (Sair):** Um botão "Sair" na tela de saudação limpa os dados do usuário (nome) e retorna à tela de login inicial[cite: 29, 40].

## Tecnologias Utilizadas

Para a construção deste projeto, foram utilizadas as seguintes tecnologias:

* **HTML5**
* **CSS3**
* **JavaScript**

O versionamento do código foi realizado com **Git**, e o projeto está hospedado no **GitHub**.

## Como Rodar/Testar a Aplicação

A aplicação está hospedada e pode ser acessada através do seguinte link:

[[**https://ps-codex.vercel.app/**]]

Para testar as funcionalidades:

1.  Acesse a tela de login e insira um nome no campo de texto.
2.  Clique no botão "Entrar".
3.  Você será redirecionado para a tela de saudação.
4.  Para alterar o nome, clique em "Editar".
5.  Para encerrar a sessão, clique em "Sair".
